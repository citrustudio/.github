# Contributing

Open an issue to discuss a change, then submit a pull request from a branch. Describe the change, the reason, tests and the issue it addresses. Use a Conventional Commits title; squash merging uses that title for the commit.

Sign off each commit to certify the [Developer Certificate of Origin](https://developercertificate.org/). Disclose AI assistance in the pull request and in an `Assisted-by` or `Co-authored-by` trailer. AI-assisted contributions receive the same review and test requirements as other contributions. Follow the Code of Conduct.
